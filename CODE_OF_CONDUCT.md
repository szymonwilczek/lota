# Code of Conduct

## Scope

This code applies to project spaces: issues, pull requests, discussions,
security reports, review comments, and community channels operated for LOTA.

## Expected Behavior

Participants are expected to:

- discuss technical disagreements with evidence and specific references,
- keep reviews focused on correctness, security, maintainability, and
  documented project goals,
- accept that security reports may require private coordination,
- respect maintainer decisions about release timing and supported scope,
- help keep contributor spaces usable for people with different experience levels.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, block
accounts from project spaces, or report abuse to the hosting provider.

Enforcement decisions should be proportional to the conduct and the risk to the
project community. Security-sensitive disruption can be handled immediately to
protect private reports and embargoed fixes.

## Reporting

Conduct issues can be reported to `swilczek.lx@gmail.com`. Security
vulnerabilities should follow [`SECURITY.md`](SECURITY.md), not this process.

Reports are handled privately. Retaliation against a reporter is unacceptable.

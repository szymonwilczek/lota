===============
Code of Conduct
===============

This code covers the project's spaces: issues, pull requests, review
comments and security reports.

Expected behaviour
==================

Participants:

* argue technical disagreements with evidence and specific references,
* keep reviews to correctness, security, maintainability and the documented
  project goals,
* accept that a security report may need private coordination,
* respect the maintainer's decisions on release timing and supported scope,
* keep the project's spaces usable for contributors of every level of
  experience.

Enforcement
===========

The maintainer may remove comments, close issues, reject contributions, block
accounts from the project's spaces, or report abuse to the hosting provider.

A measure is proportional to the conduct and to the risk it poses to the
project's community. Disruption that threatens private reports or embargoed
fixes is acted on at once.

Reporting
=========

Conduct issues go to ``swilczek.lx@gmail.com``. Reports are handled
privately, and retaliation against a reporter is not tolerated.

A security vulnerability is reported as described in :doc:`security-bugs`.

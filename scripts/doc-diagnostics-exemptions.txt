# Literals scripts/check-doc-diagnostics.sh would read as a quoted diagnostic
# and that are not one.
# Each line is a whitespace-normalised literal, matched whole.
# Keep the reason with the entry: an exemption without one is how a real
# paraphrase gets waved through later.

# A capacity formula in the sizing guide, not a message.
N instances x pool

# The three verdicts a watcher prints one at a time, written as a set.
TRUSTED / UNTRUSTED / OFFLINE

# A Go structured log line. The verifier passes the message and the attribute
# separately and the handler renders them together, so no format string in the
# tree carries the rendered text.
Postgres store initialized schema_version=1

# Output of a tool this project does not ship.
# fsverity-utils prints it when verity is already enabled on the inode,
# and the message table is built from this tree, so the gate cannot confirm
# what another program says.
FS_IOC_ENABLE_VERITY failed on '/usr/bin/lota-agent': File exists

# OpenSSL's refusal of a PIN prompt with nothing on stdin,
# quoted in the HSM example; output of a tool this project does not ship.
Could not find private key from pkcs11:...

# strerror() text for a socket errno; not a literal in this tree.
Connection reset by peer

# systemd's line after a refused watchdog kill; not a literal in this tree.
Unit process N remains running after unit stopped
